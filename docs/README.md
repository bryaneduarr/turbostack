# Documentation

Find the page that answers what you want to do.

- Run the app on a new machine: [get-started](get-started.md), the three commands and what you should see.
- Check what your machine needs: [requirements](requirements.md), tools, versions, and supported systems.
- Open the running app: [run-the-app](run-the-app.md), the addresses and how to stop.
- Run the tests: [run-tests](run-tests.md), unit, server, and browser tests.
- Run production on your machine: [run-production-locally](run-production-locally.md), the production build and containers.
- Work inside a container: [devcontainer](devcontainer.md), everything in VS Code or a terminal without host tools.
- Keep two or more projects on one machine: [multiple projects](multiple-projects.md), the shared notebook and how to set it up.
- Work in GitHub Codespaces: [codespaces](codespaces.md), the same stack in the browser.
- Fix a failed start or test: [troubleshooting](troubleshooting.md), busy ports, stopped Docker, and other common failures.
