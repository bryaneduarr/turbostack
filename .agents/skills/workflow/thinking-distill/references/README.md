| Path | Holds |
| --- | --- |
| `plan/` | How the planning session understands, critiques, asks, and summarizes |
| `plan/understand.md` | What to read, what to decide for the user, the doubts list, and the goal sentence |
| `plan/self-critique.md` | The question bank the agent runs on its own plan, the scope fence, and the critic's mission |
| `plan/asking.md` | Question rounds in chat, what never to ask, the question format, success/failure checks, and the team round |

| `run/subagent-rules.md` | Rules every subagent follows: vision, one piece, reading, container-only work, autonomy, and the report |
| `run/team-chat.md` | The team chat: post types, ids, appending, reading, and board status lines |
| `run/pr-comments.md` | `gh` commands for PR line comments, replies, and resolving threads |
| `run/jobs/` | One file per job kind: `setup`, `implement`, `merge`, `publish`, `review`, `fix`, `verify`, `record` |

| `learn/` | How plans and deliveries teach the user and learn from outcomes |
| `learn/teaching.md` | How to teach each new idea, the architecture tour, and What you learned |
| `learn/proof-and-lessons.md` | Proof levels, predictions, success and failure signals, the lessons files, and the feedback loop |
